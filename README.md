# AI Intelligent Customer Service (智语)

Microservices customer-service platform: LLM chat, knowledge RAG, tickets, WebSocket.

**Full manuals are in Chinese.** Start here:

- [中文 README](README_CN.md)
- [文档说明](docs/文档说明.md) — documentation index
- [快速开始](docs/快速开始.md) — run locally

**Stack**: JDK 17, Maven, MySQL 8, Redis 6, Gateway `:8080`, frontend `:5173`.

```bash
git clone https://gitee.com/huangrenhui/ai-cs-parent.git
cd ai-cs-parent
mvn clean install -DskipTests
```
