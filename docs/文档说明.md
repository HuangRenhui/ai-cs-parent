# 文档说明

智语智能客服（`ai-cs-parent`）**v1.0** 正式手册。现行文件为中文文件名，平铺在 `docs/` 下；另有 `database/init.sql`。

**数据库初始化仅需执行 `database/init.sql`**，包含全部 30 张表与演示种子数据。Docker 挂载需要该英文路径。列定义导读见 [数据库设计](数据库设计.md)。配置一律直接改各服务已有的 `application.yml`。

## 维护

- 改端口：改各模块 `application.yml`，再改 [系统架构](系统架构.md) 与 [快速开始](快速开始.md)。
- 改产品分期与开发顺序：改 [功能清单](功能清单.md)；代码对照写在 [项目现状](项目现状.md)。
- 改各模块能力条目：改 [模块能力](模块能力.md)。
- 工程项（Nacos、MQ、CI、覆盖率、K8s、API 签名等）：写 [功能清单](功能清单.md) §16 / §18 / §21 与 [项目现状](项目现状.md)。
- 改表结构：改 `database/init.sql` 与 [数据库设计](数据库设计.md)。**已上线的库需同步写 `ALTER TABLE` 迁移语句**（如 `cs_chat_msg.attachments`）。
- 文档修订记在本文下一节，不写进 [功能清单](功能清单.md)。
- 提示词改 [提示词说明](提示词说明.md) 与源码 `PromptConst`；模型配置改 [配置说明](配置说明.md) 与 [AI模型统一管理](AI模型统一管理.md)。
- 占位登记：写 [后端未完成清单](后端未完成清单.md) §2.1（内部方法桩）或 §2.1.1（按模块逐条），并在 §2.1.2 记录校验结果，同时同步 [接口说明](接口说明.md) 同节标注。
- 「可以页面化但还没做」的候选项（意图目录、检索参数、定时任务、告警规则等）：登记到 [提示词与向量页面配置](提示词与向量页面配置.md) §7，开工时才动代码。
- 体例：每篇含「文档信息」；篇幅较长时含「目录」；文末含「相关文档」。交叉引用使用同目录相对路径。

## 修订

| 日期 | 说明 |

| 2026-09-21 | **对话附件能力（上传 + 展示 + 落库，A 方案）**：C 端对话输入框支持**上传图片/文档、粘贴图片、拖拽文件**，可随文字一起发送，也支持「纯附件不发文字」。新增 `AttachmentDTO`、`ChatAttachmentStorageService`、`POST /file/chat-attachment`（允许全部类型，单文件 20MB，UUID 命名 + 路径校验防穿越）与 `/files/chat/**` 静态映射；`cs_chat_msg` 新增 `attachments` JSON 列，`ChatMsg` 用 `JacksonTypeHandler` 映射，`AiAgentService` 新增 `persistMessages()` 落库用户消息与 AI 回复。**放宽三处校验**支持纯附件消息：`ChatDTO.msg` 移除 `@NotBlank`、`AiAgentService` 改为「文本与附件至少有一项」、`ChatSessionService.saveMessage` 同步放宽。网关新增前置拆分路由 `/api/file/chat-attachment`，避免被知识库 `/api/file/**` 接走。前端 `ChatPage.vue` 与小程序 `chat` 页同步改造；修复流式接口 `sessionId` 为 null 时 emitters 键冲突、小程序 `question`→`msg` 字段不匹配两个隐藏问题。**AI 暂不解析附件内容**（`parseStatus=0`），多模态理解待模型层打通后回填 `extractedText` 接入 |
