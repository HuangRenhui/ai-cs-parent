## 1. 网关路由

实现：`ai-cs-gateway` `application.yml`。

| 谓词 Path | 上游 |
|-----------|------|
| `/ws/**` | `ws://localhost:8081` |
| `/ai/**` | `http://localhost:8082` |
| `/knowledge/**` | `:8083` |
| `/api/rag/**` `/api/image/**` `/api/audio/**` `/api/file/**` `/api/prompt/**` `/api/multimodal/**` `/api/document/**` `/api/knowledge-graph/**` `/api/knowledge-enhanced/**` `/api/multimodal-knowledge/**` | `:8083` |
| `/customer/**` `/session/**` `/agent/**` `/file/**` `/files/**` `/auth/**` `/statistics/**` `/system/**` | `:8084` |
| `/workorder/**` | `:8085` |
| `/open/**` | `:8086` |
| `/ops/**` | `:8087` |

知识库 `/api/file/**` 已挂网关。job `:8088` 不经网关。

全局 CORS 允许 `*`。网关 JWT 过滤器已实现：白名单仅登录、Widget 初始化、健康检查、头像静态资源、WebSocket 握手路径；`/doc.html` 与 `/actuator` 详情不再匿名。访客 JWT（`typ=visitor`）只能访问 `/ai/chat/**` 与会话写入接口。限流 Bean 仍在，路由尚未挂 `RequestRateLimiter`。

前端 Vite：`/api` → 8080（去掉 `/api`）；`/ws` → 8081。生产 Nginx 的 `location /api/` 须用 `proxy_pass http://localhost:8080/;`（末尾斜杠）剥掉 `/api`；`/ws/` 须保留路径前缀，不要写成 `proxy_pass http://localhost:8081/;`。

## 2. 对话与意图

**入口**

- REST：`POST /ai/chat/send`（`AiAgent`）
- WS：`ai-cs-websocket` → Feign `AiAgentFeign`

**意图**（识别层已配置化：`cs_intent_config` + `ConfigurableIntentService`，失败回退 `IntentEnum` 演示包；路由分支仍硬编码 5 类意图）

| 意图 | 处理 |
|------|------|
| 咨询 | `KnowledgeFeign` RAG；MISS 未命中话术，UNAVAILABLE 繁忙话术，不回退闲聊 |
| 查物流 / 退款 | `OpenToolFeign`，按 `intentBind` + 已启用行业包 |
| 投诉 | `WorkOrderFeign` 自动建单 |
| 转人工 | 固定话术，将会话类型改为人工（`PUT /session/{id}/transfer`），**仍未**排队分配坐席 |

**关键类**：`com.ai.cs.aiagent.service.AiAgentService`；提示词 `PromptConst`；模型 `ModelRouter`（未登记时回退 `DashscopeModelClient` / `ai.llm`）。`LlmUtil` 封装意图/闲聊。

目标：意图路由去枚举、提示词跟包、模型网关（清单 §15 / §6.1）。

### Agent 与知识库边界

现网会话**不在网关按消息类型分流**。聊天一律进 Agent；咨询意图由 Agent 经 Feign 调知识库。

```
用户提问（前端 /chat 或 Widget）
   ↓
Gateway：/ai/** → ai-cs-agent :8082
         （WebSocket 则先到 :8081，再 Feign Agent）
   ↓
AiAgentService 意图识别（PromptConst + DashscopeModelClient）
   ↓
   ├─ 咨询 → KnowledgeFeign RAG → 引用或未命中话术
   ├─ 查物流 / 退款（演示包）→ OpenToolFeign（MOCK 连接器）
   ├─ 投诉 → WorkOrderFeign 建单
   └─ 转人工 → 固定话术 + 会话类型改为人工（尚未排队分配坐席）
```

知识库管理接口（FAQ、文档上传、图片等）走 `/knowledge/**`、`/api/rag/**`、`/api/image/**`，由运营后台直接调用。

**分工**：agent 负责会话入口与意图路由；knowledge 负责知识内容与检索，不要再做一套会话意图枚举。聊天页只调用 `POST /ai/chat/send`（或 WebSocket），不要在浏览器里分流到 `/api/rag/chat`。不要增加 `X-Chat-Type`。

操作细节见 [知识库手册](知识库手册.md)。

|------|-------------|
| 客户 CRUD | `/customer/list|save|update|delete/{id}` |
| 坐席 CRUD/状态 | `/agent/**`；密码当前明文 |
| 会话 | `/session/ensure|list|message|/{id}/messages|/{id}/end` |

表：`cs_customer`、`cs_agent`、`cs_chat_session`、`cs_chat_msg`。

Widget 侧外部用户：`POST /open/widget/init` → `cs_visitor_map`。

## 4. 开放层

**服务**：`ai-cs-open` `OpenApplication`

| 资源 | 路径 | 说明 |
|------|------|------|
| 行业包 | `/open/pack/list`、`/{code}/enabled`、`/{code}/activate` | 电商默认开 |
| 连接器 | `/open/connector/*` | MOCK / REST |
| 工具 | `/open/tool/*`、`/invoke` | risk、intentBind、pack_code |
| Widget | `/open/widget/init` | tenantCode、visitorRef、entities |
| 场景配置 | `/open/scene-config/*` | `cs_scene_config`，场景化入口 |

调用链：仅 `enabled=1` 的 pack → MOCK 或 HTTP 到 `baseUrl+path` → 审计表。  
**禁止**在本模块建订单表。

**场景化入口**：Widget 初始化携带 `scene`（如 ORDER/PRODUCT/AFTER_SALE）与 `entities` 时，`OpenPlatformService` 按场景查 `cs_scene_config`，在 `WidgetInitVO` 下发场景化 `greeting` 与 `quickActions`（快捷动作按钮）；前端 `/widget` 渲染按钮、点击即发预设话术。实体 ID 随 `ChatDTO.entities` 传到 agent，咨询意图下拼入 RAG 检索词提升命中率。场景未配置或被禁用则回退默认欢迎语。

## 5. 知识与工单

**知识** `ai-cs-knowledge`：FAQ 分页 CRUD、租户字段、启动自动建 `cs_kb_faq`、`GET /knowledge/rag/search` 返回 HIT/MISS/UNAVAILABLE 与 citations。文档 RAG 管道（含 PDF 等）已有、半成品。生成走 `DashscopeModelClient`。未命中写入 `cs_knowledge_miss`。无助栏审核。

**工单** `ai-cs-workorder`：`GET /workorder/page`、`POST /workorder/create`、状态接口。投诉自动建单。无自定义字段、SLA、附件。

## 6. 运维台

**服务**：`ai-cs-ops` `OpsApplication`（无业务库）

| 路径 | 实现要点 |
|------|----------|
| `GET /ops/overview` | 健康计数 + 本地错误条数 |
| `GET /ops/health` | 配置的 URL 短超时探测 |
| `GET /ops/logs` | `FileLogQueryAdapter` + `LogRedactor` |
| `GET /ops/traces` | 按日志 `traceId` 聚合 |
| `GET/PUT /ops/alerts` | 内存规则 |

查询适配器可替换为 Loki/Zipkin，**前端路径不变**。

前端：`/ops`、`/ops/logs`、`/ops/traces`、`/ops/alerts`、`/ops/health`；Axios 带 `X-Request-Id`。

## 8. 统一约定

- 异常：`GlobalExceptionHandler` → `Result.fail`
- 校验：`ValidateUtil`（手机、工单类型等）
- Feign：定义在 `ai-cs-api`，url 指向 localhost 端口
- 日志脱敏（ops 返回）：手机、证件、卡号、Key、模型 prompt/messages
