## 1. 微服务架构基础
- **状态**: 已有
- **功能描述**:
  - Spring Cloud Gateway 网关服务（端口 **8080**）
  - ai-cs-websocket WebSocket 服务（端口 **8081**）— 实时通信
  - ai-cs-agent AI 代理服务（端口 **8082**）— LLM 调用、智能对话
  - ai-cs-knowledge 知识库服务（端口 **8083**）— FAQ、RAG、知识图谱、多模态
  - ai-cs-base-service 基础服务（端口 **8084**）— 客户、坐席、会话、RBAC、模型登记、意图/填槽/数据保留配置
  - ai-cs-workorder 工单服务（端口 **8085**）— 工单创建与管理
  - ai-cs-open 开放层（端口 **8086**）— 连接器、工具注册、Widget 初始化
  - ai-cs-ops 运维台（端口 **8087**）— 日志查询、健康探测
  - ai-cs-job 定时任务（端口 **8088**）— 会话清理、数据统计、缓存预热、健康检查
  - ai-cs-common — 统一返回结果、异常处理、工具类、DTO、安全注解、`ModelRouter`
  - ai-cs-api — Feign 接口定义与 Fallback
- **技术方案**: Spring Cloud Gateway；无 Nacos 时网关走本机直连
- **相关模块**: 全部微服务

## 6. RAG 检索召回优化
- **状态**: 已有
- **功能描述**:
  - **语义分层切片**（SemanticSplitService）：按段落/标题等自然语义边界切分，替代机械字符数切分，避免关键信息被切断
  - **分层切片**：文档→段落→句子→词语多粒度切分，每个 chunk 同时保留粗粒度和细粒度信息，带重叠上下文
  - **文档质量过滤**（RetrievalOptimizerService）：过滤过短/纯符号/高重复率低质文档，字符级重复度检测
  - **向量相似度初筛**：在向量检索阶段使用 minScore 做初筛，过滤不相关文档
  - **BM25 分数过滤**：关键词匹配度阈值过滤，保证关键词相关性
  - **召回数量限制**：按综合分数降序排列，取前 N 条控制上下文长度
  - **上下文摘要压缩**：总长度超限时按分数截断，对低分文档截取首尾关键句保留语义
- **技术方案**: LangChain4j DocumentSplitters + 自定义语义分隔符 + 滑动窗口重复度检测
- **相关模块**: ai-cs-knowledge
- **增强功能**: 与 [§12](#12-rag-高级功能) Rerank / ScoringModel 配合

## 7. Prompt 调试增强（六大策略）
- **状态**: 已有
- **功能描述**:
  - **角色限定**：指定身份（如领域工程师、业务面试官），System Prompt 角色定义 + 领域描述
  - **格式约束**：支持 text / json / table / bullet / strict 五种输出格式，支持 JSON Schema 字段约束和表格列定义
  - **CoT 思维链**：让模型分步思考、逐步推理，支持自定义推理步骤
  - **Few-shot 少样本**：附带 1–3 个标准答案示例，复刻格式逻辑，支持推理过程展示
  - **边界约束**：禁止编造数据、无数据兜底回复、额外行为约束，放在 System Prompt 中作为全局约束
  - **上下文约束**：可配置上下文窗口大小（字符数）、自动截断超出部分、仅基于上下文回答约束
  - **8 种预设模板**：java-engineer / interviewer / json-output / cot-reasoning / few-shot / strict-boundary / table-output / full-combo
  - **System + User 双消息模式**：支持 system+user 双消息发送给 LLM
  - **Prompt 调试 API**（PromptDebugController）：查看/切换预设、预览 System/User Prompt、动态修改配置、查看 OpenAI messages 格式
  - **配置热切换**：`application.yml` 预设 + 运行时动态修改 + 一键重置
  - **调试日志**：debug-log 模式下打印完整 System Prompt 和 User Prompt
- **技术方案**: PromptTemplateService + PromptProperties + PromptDebugController + LlmClient.callWithSystem()
- **相关模块**: ai-cs-knowledge
- **增强功能**: 见 [提示词说明](提示词说明.md)

## 13. 多媒体文件处理
- **状态**: 已有（基础） / 半成品（增强）；**仅知识库**，会话气泡见 [功能清单 §9](功能清单.md)
- **功能描述**:

### 13.1 图片上传与处理
  - 图片文件上传（JPG、PNG、GIF、WEBP、BMP 等）
  - 图片压缩处理（自动压缩大图片，可配置阈值和质量）
  - 图片元数据提取（EXIF：相机型号、拍摄时间、GPS 等）
  - 图片格式转换（主流格式互转）
  - 图片缩略图生成（可配置尺寸，保持宽高比）
  - 图片尺寸调整（支持保持/不保持宽高比）
  - 图片裁剪（按坐标和尺寸裁剪）
  - 图片水印添加（支持位置、透明度配置）
  - 使用说明见 [知识库手册](知识库手册.md)
- **增强功能**:
  - 对象存储集成（本地 / MinIO / OSS / COS 多种存储策略）
  - CDN 加速（可配置 CDN 域名，自动生成 CDN 访问 URL）
  - 批量上传和处理（并发处理、进度追踪）
  - 图片 OCR 文字识别（提取图片中文字用于知识库检索）
  - 图片 AI 审核（内容安全检测框架，可对接第三方审核 API）
  - 图片智能标签（基于元数据自动生成标签，支持预定义标签库）
  - 图片去重检测（感知哈希 pHash / dHash，精确匹配和相似检测）
  - 图片版本管理（多版本创建、切换、回退、差异对比）
  - 图片访问统计（浏览量、下载量、分享量，热门排行）
  - 图片防盗链（Token 验证、Referer 白名单、签名 URL）

### 13.2 音频上传与处理

  - 音频格式转换（主流格式互转）
  - 音频时长提取（精确到秒，支持格式化显示）
  - 音频波形可视化（生成 PNG 波形图，可配置尺寸）
  - 音频元数据提取（比特率、采样率、声道数、艺术家、专辑等）
  - 自动压缩（超过阈值自动压缩，可配置压缩参数）
- **增强功能**:
  - 真实波形图生成（FFmpeg / Java Sound API，支持立体声分声道）
  - 批量上传和处理（并发处理、进度追踪）
  - 音频语音识别 ASR（Whisper 集成框架，将语音转为文字）
  - 音频 AI 审核（内容安全检测框架）
  - 音频智能标签（基于元数据自动标签）
  - 音频去重检测（音频指纹，精确匹配和相似度匹配）
  - 音频版本管理（多版本创建、切换、回退）
  - 音频访问统计（播放量、下载量，热门排行）

### 13.3 图片/音频向量化与入库

  - 音频元数据/转录文本向量化（基于文件名、时长、格式、元数据等生成描述）
  - 向量化存储到 Chroma（图片集合、音频集合分别存储）
  - 自然语言语义搜索（按描述搜索相似图片/音频）
  - 批量向量化支持
  - 上传后自动向量化（可配置）
- **增强功能**:
  - 多模态混合检索（图文音频融合搜索，结果统一排序）
  - 跨模态语义搜索（用图片描述搜音频，或反之）
  - 图文混合问答（结合图片和文本知识库的综合检索）

### 13.4 文件查看、下载与解压
  - 文件在线预览（图片、PDF、音频、视频，浏览器内联展示）
  - 按文件 ID 预览（images / audios / documents / thumbnails 等存储类型）
  - 文件下载（Content-Disposition: attachment，支持 HTTP Range 断点续传）

  - 批量文件打包下载（多文件打包为 ZIP）
  - 压缩包内容查看（不解压即可浏览包内文件列表）
  - 解压后文件预览与列表查看
  - Zip 炸弹防护（限制解压大小和文件数量）
  - Zip Slip 路径穿越攻击防护
  - 文件信息查看（大小、类型、是否可预览等元数据）
  - 目录文件列表（支持递归列出子目录）
  - 静态资源 URL 映射（支持直接 URL 访问文件）
  - CORS 跨域访问配置

- **技术方案**: Thumbnailator、JAVE2 / FFmpeg、LangChain4j、Chroma、Apache Commons Imaging / Compress、Java Sound API
- **相关模块**: ai-cs-knowledge
