## 🔄 数据流向概览

详细的业务流程和数据流向请查看 [数据流向文档](data-flow.md)。

### 核心业务流程

1. **用户聊天流程**
   ```
   用户 → 前端 → WebSocket → AI代理 → LLM → 知识库检索 → 返回答案
   ```

2. **工单创建流程**
   ```
   用户/坐席 → 前端 → 网关 → 工单服务 → 数据库 → 通知坐席
   ```

3. **知识检索流程**
   ```
   问题 → Embedding → 向量 → Chroma/Milvus检索 → Rerank重排 → 相似FAQ → LLM生成答案 → 返回
   ```

## 🛡️ 安全设计

1. **网关鉴权**: 所有请求经过网关进行身份验证
2. **密码加密**: 坐席密码使用 BCrypt 加密存储
3. **HTTPS**: 生产环境使用 HTTPS 协议
4. **SQL 注入防护**: 使用 MyBatis Plus 参数化查询
5. **XSS 防护**: 前端输入过滤和转义
6. **CSRF 防护**: Token 验证机制

---

## ⚡ 性能优化

1. **Redis 缓存**: 热点数据缓存，减少数据库查询
2. **数据库索引**: 合理设计索引，优化查询性能
3. **连接池**: 使用 HikariCP 数据库连接池
4. **异步处理**: 耗时操作异步执行
5. **分页查询**: 大数据量使用分页
6. **向量检索优化**: Milvus 索引加速相似度搜索

---

## 📊 监控与日志

1. **Spring Boot Actuator**: 健康检查和指标监控
2. **日志收集**: 统一日志格式，支持 ELK 分析
3. **链路追踪**: 集成 Sleuth/Zipkin（可选）
4. **告警机制**: 关键指标异常告警

---

## 🔮 扩展性设计

1. **微服务架构**: 各服务独立部署，易于扩展
2. **无状态设计**: 服务无状态，支持水平扩展
3. **消息队列**: 可集成 RabbitMQ/Kafka 解耦（未来）
4. **配置中心**: 可使用 Nacos 统一管理配置（未来）
5. **服务注册**: 可集成 Nacos/Eureka 服务发现（未来）
