## 1. 模块分层（目标 vs 现状）

| 层 | 目标模块 | 现状 |
|----|----------|------|
| 渠道 | C 端 Widget/SDK、坐席台、企微/热线 | 仅运营后台 `/chat`；已有 `/widget` 可嵌页面（SDK 雏形） |
| 会话内核 | 会话、排队、机器人、工单、知识 | 会话/机器人/工单/知识 **已有**；排队/技能组 **缺失** |
| 平台 | 租户、IAM、审计、质检、报表 | **半成品**：登录/JWT/RBAC 已有；审计/多租户/质检仍缺 |
| 开放 | 连接器、工具注册、Webhook、卡片、身份映射 | 已有脚手架：`ai-cs-open`（连接器 + 工具 + Widget 初始化 + MOCK 调用）；Webhook/卡片协议仍缺 |
| 行业包 | 电商/零售/金融预置工具 | 意图写死在 `IntentEnum`；演示工具改为走 MOCK 连接器，**不是**订单表 |

当前可运行微服务：gateway 8080、websocket 8081、ai-agent 8082、knowledge 8083、base 8084、workorder 8085、**open 8086**、**ops 8087**、**job 8088**、frontend **5173**。无 Nacos 时网关走本机直连；`ai-cs-job` 已有会话清理/统计/预热/健康检查，向量对账仍缺。

## 3. 代码入口

| 能力 | 位置 |
|------|------|
| 连接器 / 工具 / 行业包 | `ai-cs-open`，网关 `/open/**` |
| Widget 初始化 | `POST /open/widget/init` |
| C 端页面 | 前端 `/widget`（`meta.blank`，可 iframe） |
| 运营配置 | 前端 `/open`（包开关、连接器、工具） |
| 运维台 | `ai-cs-ops` :8087，网关 `/ops/**`，前端 `/ops` |
| 机器人调工具 | `AiAgentService` → `OpenToolFeign` |
| 大模型 | `DashscopeModelClient`（chat + embed），配置 `ai.llm` / `ai.embedding`；提示词 `PromptConst`；尚无管理页 |
| 头像 | `POST /file/avatar`，静态 `/files/avatars/**` |
| 禁止事项 | **无** `OrderService` / 订单表 |
